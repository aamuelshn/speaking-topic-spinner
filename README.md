# Speaking Topic Spinner

An interactive public-speaking practice app that rapidly cycles through prompts before selecting a random topic.

## Features

- 185 speaking and interview prompts
- Animated random topic selection
- Behavioral, logic, reflection, debate, storytelling, and persuasive modes
- Adjustable practice timer
- Difficulty challenges, quick notes, and recent-topic history

The app is a standalone static website. Open `index.html` locally or deploy the folder to any static host, including Vercel.
